# VSAT Multimeter OCR for Nelco
Computer Vision and OCR System for identifying multimeters and extracting measuremnts from VSAT/SDWAN site images.

 ## Project Goal
 The System will:
 1. Detect the multimeter in the site image.
 2. Detect the multimeter display.
 3. Crop and process the display
 4. Extract the sisplayed measuremnt using OCR.
 5. Parse and Validate Measurement

# Technology
- Python
- YOLO
- OpenCV
- Numpy
- Pandas
